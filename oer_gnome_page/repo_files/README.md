# OER-GNoME

An exploration log from an autonomous DFT screening campaign for oxygen
evolution catalysts: every candidate the agent considered, the calculations it
launched, and the reasoning behind each decision it took — including the paths
it abandoned.

**→ [Browse the database](https://matminator.github.io/OER-GNoME/)**

`index.html` is the whole thing — data, plots and 3-D structure viewer in one
self-contained file, with no dependencies. Licence, attribution and method
notes are on the site's own tabs.

Data: **CC BY-NC 4.0**, non-commercial use only, inherited from GNoME.

This repository is regenerated and force-replaced on each publish, so it holds
only the current snapshot. The code that builds it lives in
[BattModels/material_agent](https://github.com/BattModels/material_agent/tree/oer_resume_extented_workflow).
